## Alien Ink Abstraction and Development Guidelines

### In the Abstract

* Alien Ink is a personal library for model training
* Model training is a form of creating artifacts
* A manifest is an abstract container of all the variables for a training run
* Each manifest includes config for model, dataset, trainer, hardware, etc
* The zdeck is an archive of manifests for historical record or future re-use
* The manifests are written in alien ink and stored in the zdeck

### Development principles

* Clean, tight, and composable code
* Functions are favored over classes or complex structures
* Each package and module are semantically well encapsulated
